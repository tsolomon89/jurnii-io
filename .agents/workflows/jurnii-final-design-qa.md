# Workflow: Jurnii Final Design QA

## Description
Runs a full-site review and produces the final orchestration report.

## Steps
1. **Checklist Review:** Verify all items in `JURNII_DESIGN_QA_CHECKLIST.md` are marked complete for every prioritized page.
2. **Cross-Page Consistency:** Verify that shared components (nav, footer, cards) maintain consistent styling and token usage across all routes.
3. **Artifact Gathering:** Collect all generated screenshots, recordings, and implementation notes.
4. **Compile Report:** Create `JURNII_DESIGN_ORCHESTRATION_REPORT.md` documenting:
   - Pages audited and upgraded.
   - Components created or improved.
   - Browser QA artifacts produced.
   - Any unresolved issues or recommendations for the next pass.
