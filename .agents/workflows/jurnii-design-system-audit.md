# Workflow: Jurnii Design System Audit

## Description
Audits tokens, CSS, components, colours, typography, spacing, responsive rules, and reusable section patterns.

## Steps
1. **Analyze Existing CSS:** Review `assets/colors_and_type.css` and `assets/site.css` to map current variables, fonts, and layout logic.
2. **Identify Weaknesses:** Note brittle structures (e.g., global namespace pollution, duplicate component HTML).
3. **Draft Design System:** Create `JURNII_WEB_DESIGN_SYSTEM.md` defining strict tokens, layout rules, CTA styling, and dashboard panel usage based on the Jurnii Brand Context.
4. **Compile Component Backlog:** Create `JURNII_COMPONENT_BACKLOG.md`, identifying reusable components that need to be built or refactored (e.g., metric strips, product proof cards, competitor benchmark tables).
