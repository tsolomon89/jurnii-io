# Workflow: Audit Current Site

**Purpose**: Inspect the current website before redesigning.

Follow these steps exactly, without making any modifications to the codebase:

1. **Load Skills**: Read `.agents/skills/writing/SKILL.md` to understand the commercial ontology grammar.
2. **Identify Technical Stack**: Identify the framework, routing approach, and styling system.
3. **Phase 1: Extract Ontology**: Inventory the current site to identify the Brand, Products (stable noun phrases), Features (object nouns), Solutions (nominalised operators), Use Cases, and Personas. Flag any grammatical violations against the ontology.
4. **Phase 2: Architecture Audit**: Map existing pages to the Four Pillars (Products, Features, Solutions, Use Cases). Identify any pillar gaps, orphan pages, or pages that conflate multiple pillars.
5. **Output Artifact**: Output a comprehensive audit artifact summarizing the findings against the Commercial Ontology without making any code changes.
