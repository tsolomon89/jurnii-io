# Jurnii Site Content Matrix (Strict Commercial Ontology)

This matrix is the single source of truth for the generation of all detail pages on the Jurnii.io static site. It strictly adheres to the Commercial Ontology Grammar (Products = Noun Phrases, Features = Object Nouns, Solutions = Nominalised Operators).
