# Jurnii Site Content Matrix (Strict Commercial Ontology)

This matrix is the single source of truth for the Jurnii.io static site ontology. It strictly adheres to the Commercial Ontology Grammar.
- Products = Noun Phrases
- Feature Objects = Object Nouns
- Solution Operators = Nominalised Operators
- Use Cases = Field Names
- Values = Allowed entries under fields

## 1. Products

### Jurnii UX
- **Category:** Product
- **Page Slug:** `/products/jurnii-ux.html`

### Jurnii 360
- **Category:** Product
- **Page Slug:** `/products/jurnii-360.html`

### Cortex
- **Category:** Product
- **Page Slug:** `/products/cortex.html`

### Jurnii Studio
- **Category:** Service Product / Delivery Product
- **Page Slug:** `/services/jurnii-studio.html`

## 2. Feature Objects (Canonical)

Must be object nouns.
- **Jurnii UX:** Journeys, Usability, Performance, Perception
- **Jurnii 360:** Promotions, Offers, Banners, Segments, Trends, Alerts, Database, Exports
- **Cortex:** Assistant, Reports, Scenarios, Budgets, Channels, Models

## 3. Solution Operators (Canonical)

Must be nominalised operators.
- Benchmarking, Tracking, Alerting, Attribution, Modelling, Reconciliation, Planning, Reporting, Optimisation, Analysis, Measurement, Design, Experimentation

## 4. Use Case Fields & Values

### Field: Industry
- **Values:** Operators, Suppliers

### Field: Role
- **Values:** CPO, CCO, CMO, CEO, Head of CRM, Head of UX

## 5. Persona Types
- Decision Maker
- End User
- Influencer
