# Rule: Jurnii Design Quality Gates

## Description
Defines the completion criteria for any page redesign or visual update.

## Directives
1. **Quality Gates:** A page is not complete until it passes all of the following checks:
   * **Brand Check:** Aligns with Jurnii brand and tone rules.
   * **UX Check:** Commercial hierarchy is clear, CTA is visible without scrolling.
   * **Responsive Check:** Verified on mobile, tablet, and desktop viewports.
   * **Accessibility & Contrast:** Verified legible and navigable.
   * **Browser Validation:** Opened and reviewed via the browser subagent.
   * **Screenshot Evidence:** WebP recordings or screenshots are captured as evidence of visual completion.
2. **Defect Resolution:** Any visible defects found during browser QA must be fixed before the task is marked complete.
