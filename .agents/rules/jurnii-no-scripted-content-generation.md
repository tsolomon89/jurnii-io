# Rule: No Scripted Content Generation

## Description
Prohibits the use of scripts to mass-generate content or pages.

## Directives
1. **No scripts for copy generation:** You must not write or run Node.js/Python/Bash scripts that generate page copy, marketing copy, or HTML content sections.
2. **Allowed script usage:** Scripts may only be used for auditing, validation, testing, link checking, or reporting.
3. **Direct authoring:** Copy and design decisions must be directly authored by the agent in the source files after reading the Jurnii brand context. Do not use generic SaaS templates to fill sections.
