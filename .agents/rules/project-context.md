# Project Context

- **Project Identity**: This is the Journey.io / Jurnii.io website redesign/rebuild project.
- **Goal**: The primary objective is to create a commercially effective website, not merely a visual refresh.
- **Business Alignment**: The site must support product positioning, persona clarity, conversion paths, and future CRM/analytics alignment.
- **Systems Thinking**: The website should be treated as part of a wider go-to-market system, mapping directly to our commercial ontology.
