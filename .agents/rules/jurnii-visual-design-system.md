# Rule: Jurnii Visual Design System

## Description
Enforces the premium, enterprise iGaming visual identity.

## Directives
1. **Enforce Brand Variables:** Strictly use Jurnii CSS tokens for colour, typography, spacing, and data visualization.
2. **Typography:** Use Geist for primary text, Geist Mono for metrics/code, and Cormorant Garamond italic only for rare editorial emphasis.
3. **Section Hierarchy:** Use dark brand backgrounds for primary hero and strategic arguments. Use off-white/elevated white for product explanation and data clarity.
4. **Accent Usage:** Use brand green (`#94ff96`) for CTAs, highlights, and hero emphasis. Do not overuse green.
5. **Component Patterns:** Rely on structured data panels, metric blocks, comparison tables, and dashboard cards.
6. **Prohibitions:** Prevent generic SaaS templates, cyberpunk styling, decorative AI graphics, startup-template styling, and over-animated landing pages.
