# Website Redesign Standards

When executing a redesign or page change, you must:

- **Understand First**: Fully understand the existing page structure, functionality, and content before attempting to change it.
- **Identify Core Elements**: Identify the page's core purpose, target persona, conversion goal, and content hierarchy.
- **Preserve SEO**: Preserve or improve SEO-critical structure (e.g., proper heading hierarchy, meta structures).
- **Avoid Generic Copy**: Avoid generic SaaS copy. Use precise language mapped to the commercial ontology.
- **Maintain Conversion Focus**: Avoid visual changes that weaken clarity, credibility, accessibility, or conversion rates.
- **Holistic View**: Treat design, copy, structure, and analytics as one cohesive system, not isolated elements.
