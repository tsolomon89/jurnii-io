# Rule: Jurnii Agent Operating Principles

## Description
Core operational guardrails for all agentic actions within the Jurnii workspace.

## Directives
1. **Always load brand context:** Before making any website copy or design changes, you must read the relevant brand context summaries.
2. **Never make unsupported claims:** Do not invent features, metrics, or capabilities.
3. **Never treat design as decorative:** All design decisions must serve a commercial purpose.
4. **Support commercial clarity:** Every design change must clarify the commercial hierarchy and guide the primary buyer.
5. **Browser verification is mandatory:** Visual work is not complete until validated via the browser subagent.
