# Jurnii Design QA Checklist

Before marking a page redesign as complete, verify the following:

## Brand & Content
- [ ] **Brand Fit:** Does it feel like an enterprise iGaming intelligence platform? (Calm authority, premium, non-decorative).
- [ ] **Commercial Hierarchy:** Does every section clarify a commercial problem and present Jurnii's solution?
- [ ] **Specific CTA:** Is there a clear, specific CTA (e.g., "Book a Demo") visible above the fold and at the bottom?
- [ ] **Proof-Point Accuracy:** Are numbers (+46%, 3x, 40x, 300+ brands) used accurately and without invention?

## Visual & Layout
- [ ] **Contrast:** Do all text elements meet WCAG AA contrast ratios (especially brand green)?
- [ ] **Visual Rhythm:** Is the spacing consistent, based on the 4px grid? Do sections breathe?
- [ ] **Typography:** Is Geist used correctly? Are metrics using Geist Mono? Is Cormorant Garamond limited to one italic instance max?

## Technical & Responsive
- [ ] **Desktop Layout:** Verified at 1280px+. No broken grids or misaligned elements.
- [ ] **Tablet Layout:** Verified at 768px. Content reflows properly.
- [ ] **Mobile Layout:** Verified at 375px. Multi-column layouts stack. Touch targets are large enough. Navigation collapses properly.
- [ ] **Navigation & Footer:** Ensure existing header and footer functionality is preserved.
- [ ] **Accessibility:** Elements are keyboard navigable and logically structured.
- [ ] **Build/Lint/Test Status:** Any relevant HTML validations pass.

## Validation Artifacts
- [ ] **Browser Screenshots:** Captured desktop, tablet, and mobile screenshots using the browser subagent.
