# Nano Banana Image Generation

This skill governs the use of Nano Banana to generate supporting atmospheric interface imagery for Jurnii artifacts.

## Core Directives

1. **Atmospheric Support Only**: Use Nano Banana for atmospheric, generated interface imagery only. Generated images support the page but do not replace structured HTML/SVG interface artifacts.
2. **No Text or Logos**: Generated images must contain absolutely no readable text, words, or corporate logos.
3. **No Gambling Clichés**: Generated imagery must look like premium B2B commercial intelligence software. Strictly avoid dice, cards, roulette wheels, slot machines, or casino floor depictions.
4. **Visual Style**: Prompts should request dark graphite interfaces, precise neon green accents, glass panels, and abstract data visualisations. Always specify a 16:9 aspect ratio.
5. **Asset Storage**: Save generated assets under `assets/images/generated/`.
6. **Documentation**: Always save the prompts and output paths. Commit the generated assets or the documented prompts to the repository.
