## 16 high-severity journey pain points (with fixes / benchmark refs)
- **[Entry] Visual overload on arrival** — prioritise one hero banner, segment into collapsible carousels.
- **[Sign-in] Log In / Register CTAs hidden behind account icon** — expose both in header (BetClic reference).
- **[Sign-in security] No CAPTCHA / anti-bot on login** — implement invisible CAPTCHA (Unibet.fr reference).
- **[Registration] Post-registration orientation absent** — add post-reg dashboard (deposit, verify, place a bet).
- **[Finding Bets] No search input/icon in header** — add visible search + auto-suggestions (Bet365 benchmark).
- **[Finding Bets] Search/sorting partially invisible** — make search visible, enable sorting (Unibet reference).
- **[Finding Bets] No favouriting** for sports/events — add star/heart (Unibet, Winamax references).
- **[Betslip] Betslip CTA below the fold** — sticky CTA with stake/returns/confirm always visible.
- **[Betslip] Shopping-basket icon non-standard** — use standard sportsbook iconography + sticky footer.
- **[Depositing] Error messages provide no recovery route** — surface alternative payment/support inline.
- **[Depositing / safer gambling] Deposit-limit settings completely absent** — add visible deposit limit (regulatory + trust risk; Unibet reference).
- **[Depositing] Zero transaction-fee information** — display fees adjacent to payment method.
- **[Bonus] T&Cs hidden behind a CTA** — surface direct plain-language links on each promo card.
- **[Bonus] No opt in/out controls** — add toggle in account settings (trust + regulatory risk).
- **[Getting Help] 24/7 availability not indicated** — display prominently (Winamax.fr model).
- **[Getting Help] Email and live chat absent/buried** — elevate contact options in help section.
