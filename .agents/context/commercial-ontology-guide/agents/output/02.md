## keywords: jurnii, architecture, pillar, URL, relational-graph, self-qualification, cross-links

Completed Phase 2 architecture mapping on 2026-05-11. Output at /mnt/user/outputs/02-architecture-map.json.

## Pillar Distribution (primary classification)
- Products: 3 pages (/ux, /360, /studio) — all conflated with other pillars
- Solutions: 3 pages (/services/cro, /services/analysis, /services/design-solutions) — all conflated with Features+UseCase
- Use Cases: 1 page (/case-studies index only) — no individual use-case pages
- Features: 0 pages (23 features in ontology, none have dedicated pages)
- No pillar: 1 (/about — company narrative)
- Homepage: conflated (Products + Solutions + Features + UseCase — all four)
- Total conflated pages: 8 of 9

## URL Structure
- /ux, /360, /studio — flat, no /products/ namespace
- /services/cro, /services/analysis, /services/design-solutions — /services/ namespace (not /solutions/)
- /case-studies — index only, no /use-cases/[dimension] hierarchy
- No /features/ namespace at all
- Individual case studies at /case-study/[slug] (singular), not /use-cases/[dimension]/[slug]

## Cross-Link Counts (body-level, not nav/footer)
- Product→Product: 2 (sibling widget on /ux↔/360)
- Product→UseCase: 8 (case study sections on product pages)
- Solution→UseCase: 3 (case study section on /services/cro)
- Solution→Solution: 2 (sibling cards at bottom of service pages)
- Studio→Solution: 3 (service cards on /studio)
- Product→Solution: 0 (NO body links from /ux or /360 to /services/*)
- Solution→Product: 0 (NO body links from /services/* to /ux or /360)
- Feature→Product: 0 (no feature pages)
- Solution→Feature: 0 (no feature pages)
- UseCase→Solution: 0
- UseCase→Product: 0

## Self-Qualification
- Nav groups: "Products" (UX, 360) + "Services" (Studio + 3 sub-services)
- No industry/role/company-type navigation paths
- Pages are dense (10+ content modules each) — not one subject per page
- No persona-based routing

## Key findings for Phase 3
1. Features pillar entirely absent — 23 features have zero standalone pages
2. Product→Solution disconnect: visitors on /ux or /360 have no in-page path to Studio services
3. Solution→Product disconnect: visitors on service pages cannot discover AI products without navbar
4. Use case pages not segmented by ontology dimensions (Industry, Company Type, Department, Engagement Model)
5. URL namespace wrong: /services/ should be /solutions/, /ux should be /products/jurnii-ux
