# Transition Cost Modelling

## Quick start

1. Read all prior outputs from `/mnt/user/outputs/` (01 through 04)
2. Calculate four cost categories using the formulas below
3. Write the cost model to `/mnt/user/outputs/06-transition-costs.json`

## What this skill does

Takes all prior phase outputs as input and quantifies the effort to bridge the gap between the current site state and the framework-organised structure. The output is a **structured cost model** — hours, timelines, and team requirements derived from concrete counts in the prior maps.

## Cost categories

**Retagging**: Classifying existing content against the ontology.

**Restructuring**: Reorganising content to match the four-pillar model.

**Learning curve**: Team adoption of ontology vocabulary and processes.

**Transition period**: Parallel-run impact on velocity and reporting.

## HONESTY RULE

Estimates MUST be realistic, not optimistic. Round UP, not down.
