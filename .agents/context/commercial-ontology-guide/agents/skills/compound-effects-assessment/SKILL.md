# Compound Effects Projection

## Quick start

1. Read all prior outputs from `/mnt/user/outputs/` (01 through 04)
2. For each of the five effect domains, trace what the current structure produces
3. Write the projection to `/mnt/user/outputs/05-compound-effects-map.json`

## What this skill does

Takes all prior maps and **projects forward**: given the entity structure, page architecture, copy grammar, and CRM mapping that now exist, what does each domain look like? The output describes the observable state of each domain — not whether conditions are "met" but what the structure actually produces.

## Effect domains

| Domain | What to describe |
|:---|:---|
| Site | How visitors navigate: what paths exist, how many clicks between entity types, what the page structure exposes |
| Pipeline | What CRM events the current structure can generate, what fields get populated, how stages could transition |
| Marketing | What experimental variables the entity inventory provides, what attribution the typed coordinates enable |
| Team/Cultural | What vocabulary the entity map establishes, where source names and framework names diverge |
| Asset Compounding | How new pages relate to the existing dataset, what the entity graph's growth pattern looks like |

## Key principle

Describe what **is**, traced to the maps. Don't evaluate what **should be**.
